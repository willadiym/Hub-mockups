# Короткая спецификация: Бэклог N1

## Сущности

1. **Запись бэклога** — единая сущность для пользовательской идеи и фичи.

   Поля: название, описание, категории, статус, автор, голоса, квартал реализации, признак архивации и комментарий отклонения.

2. **Категория** — запись может относиться к одной или нескольким категориям.

3. **Пользователь** — предлагает идеи, просматривает доступный ему бэклог и голосует.

4. **Администратор** — модерирует идеи, добавляет фичи напрямую, редактирует, архивирует и восстанавливает записи.

## Жизненный цикл

`На модерации → Идея → Запланировано → В работе → Уже доступно`

Из модерации запись также может перейти в статус «Отклонено». Архив — отдельный признак записи, а не этап жизненного цикла: при архивации текущий статус сохраняется.

Администратор может создать запись сразу в нужном статусе или изменить статус через редактирование.

## Статусы и действия

| Статус | Значение | Действия пользователя | Действия администратора |
|---|---|---|---|
| На модерации | Новая неопубликованная идея | Автор просматривает свою идею | Отклонить с обязательным комментарием, опубликовать, редактировать, архивировать |
| Отклонено | Идея не прошла модерацию | Автор видит идею и комментарий администратора | Редактировать, архивировать |
| Идея | Опубликованное предложение без обязательств по реализации | Просмотр, голосование | Редактировать, запланировать, архивировать |
| Запланировано | Фича включена в план | Просмотр, голосование, просмотр квартала | Редактировать, перевести в работу, архивировать |
| В работе | Реализация началась | Просмотр, голосование, просмотр квартала | Редактировать, отметить доступной, архивировать |
| Уже доступно | Фича реализована | Просмотр информации без голосования | Редактировать, архивировать |

Для любой архивной записи администратору доступны просмотр, редактирование и действие «Вернуть из архива». Восстановление возвращает запись в сохранённый статус.

## Основные сценарии

### Предложение идеи

Пользователь заполняет название, описание и одну или несколько категорий. Запись получает статус «На модерации» и отображается только автору и администраторам. После публикации она переходит в «Идеи пользователей». При отклонении администратор обязан оставить комментарий; автор продолжает видеть идею со статусом «Отклонено» и этот комментарий.

### Добавление администратором

Администратор задаёт название, статус, категории, квартал и описание. После сохранения запись появляется в соответствующем разделе, а интерфейс показывает зелёный снекбар.

### Редактирование

Из просмотра карточки администратор нажимает «Редактировать». Сайдбар переключается в форму с заполненными данными. После сохранения карточка автоматически перемещается в новый статус или категории.

### Архивация

Кнопка «Архивировать» ставит признак архивации, сохраняя текущий статус записи. Запись исчезает из активного статуса и появляется во вкладке «Архив», доступной только администраторам. Действие «Вернуть из архива» снимает признак и возвращает запись в прежний статус.

## Видимость и голосование

- Идеи «На модерации» и «Отклонено» видят только администраторы и автор конкретной идеи.
- Архивные записи и вкладку «Архив» видят только администраторы.
- Голосование доступно для опубликованных идей, запланированных записей и записей в работе.
- Голосование отключено для модерации, отклонённых, уже доступных и архивных записей.

## Поиск и фильтрация

- Фильтры по статусам и категориям взаимоисключающие.
- Категория показывает доступные текущему пользователю записи всех статусов.
- Поиск применяется поверх выбранного фильтра.
- Счётчики отражают фактическое количество видимых карточек.
- Пустые категории отключаются и перемещаются вниз.
- Порядок карточек: идея → запланировано → в работе → доступно. В архиве используется сохранённый статус для сортировки.
- В статусной вкладке соответствующий бейдж на карточке не повторяется.
