# N1 Hub — доступность

React 18 + Vite 6 + Consta UI Kit 5.33.3 + @consta/icons 1.7.1.

## Репозиторий и постоянный стенд

Основной репозиторий: https://github.com/willadiym/Hub-mockups. Эта папка — его локальная рабочая копия. Изменения делаются здесь, проверяются, фиксируются коммитами и отправляются в `origin`. Другой проект в родительской папке в этот репозиторий не входит.

При отправке в `main` сценарий `.github/workflows/pages.yml` устанавливает закрепленные зависимости, собирает все страницы и публикует `dist` в GitHub Pages. Изменения в pull request проходят сборку без публикации. Для первого включения Pages в настройках репозитория выбирается источник **GitHub Actions**.

Адрес после успешной публикации: https://willadiym.github.io/Hub-mockups/. Настройки уведомлений: https://willadiym.github.io/Hub-mockups/notifications.html. Бэклог N1: https://willadiym.github.io/Hub-mockups/backlog.html. Такой стенд работает независимо от этого Mac и чата. Публикация закрытого репозитория через GitHub Pages зависит от тарифа GitHub; видимость репозитория не меняется автоматически.

В CI используется `VITE_BASE_PATH=/Hub-mockups/`. Локально базовый путь `/`; общая функция `src/paths.js` сохраняет корректные переходы и загрузку логотипа в обоих случаях.

## Бэклог N1

Страница `backlog.html` — отдельная точка входа с прототипом бэклога. Исходники находятся в `src/backlog/`, а краткая функциональная спецификация — в `docs/BACKLOG_SPEC.md`, поэтому развитие бэклога не затрагивает страницы доступности и уведомлений. Макет использует Consta UI Kit, поддерживает фильтрацию по статусам и категориям, поиск, голосование, предложение идей и административные сценарии модерации, редактирования и архивации. Данные демонстрационные и хранятся только в состоянии страницы.

## Настройка уведомлений

Кнопка «Подписаться» и пункт «Настройка уведомлений» в меню пользователя открывают `/notifications.html`. Страница реализована на React и Consta, исходный HTML служит только образцом. Маркетинговые и технические рассылки показаны без боковых панелей. Все 17 сервисов из `src/data.js` сгруппированы по фактическим регионам из `unitsFor`: «Центральный», «Среда разработки» и «Общие сервисы» для порталов. У сервиса в разных регионах независимые подписки. Старый выбор сервисов автоматически переносится в региональные подписки.

Переключатель внизу страницы показывает три сценария: «Участник проекта», «Без проекта» и «Команда Hub». В сценарии команды доступны получатели, исключения и ручное добавление адресов. В демонстрационном списке автосборки — 1 200 участников проектов и несколько отдельных получателей; личных подписок только три. Тип человека — «Пользователь N1», источник автоматического включения — «Участник проекта». Таблица показывает по восемь строк на страницу. Личные настройки пользователя имеют приоритет над настройками команды. Это переключение прототипа, а не авторизация.

«Копировать список» всегда открывает окно выбора количества адресов в группе. После формирования можно копировать каждую группу или показать адреса для ручного копирования. Учитывается полный список выбранной рассылки и вкладки с личными настройками и исключениями, независимо от поиска и страницы. Адреса не повторяются между группами.

Компоненты и модель находятся в `src/notifications/`, отдельная точка входа — `notifications.html`. Настройки сохраняются в этом браузере; отправка писем и серверная интеграция не подключены. Адреса в административном сценарии демонстрационные. Сборка Vite включает обе страницы. Содержание статусной страницы не менялось; в её шапке подключено общее меню `src/UserMenu.jsx` с пунктами «Настройка уведомлений» и «Выйти». Выход завершает только демонстрационную сессию в текущей вкладке и открывает статусную страницу; для возврата есть кнопка «Войти». Интеграция с системой авторизации отсутствует.

## Запуск

С установленными Node.js 24 и pnpm 11.25.0:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Сборка: `pnpm build`. Просмотр сборки: `pnpm preview`. Проверка варианта для GitHub Pages: `VITE_BASE_PATH=/Hub-mockups/ pnpm build`, затем `VITE_BASE_PATH=/Hub-mockups/ pnpm preview`. Исходники, документация и lockfile хранятся в Git, а зависимости, сборка, логи и локальные настройки — нет.

`src/main.jsx` — компоненты и взаимодействия, `src/style.css` — оформление, `src/data.js` — сервисы, кластеры и демонстрационные события. `public/logo.png` — предоставленный логотип.

Фильтры используют кнопки Consta с Popover и Checkbox. При множественном выборе отображается количество значений, высота кнопки остаётся 32 px. Пустой выбор включает все значения. Внутри фильтра значения объединяются по ИЛИ, между фильтрами — по И. События открываются в ленте с выделением и прокруткой. Календарь показывает 90 дней по московским календарным датам. Время событий задано как московское.

История и статусы демонстрационные. Уведомления и мониторинг не подключены. Региональная привязка глобальных сервисов в демонстрационных данных требует уточнения перед интеграцией. Центральные локации в фильтре объединены с регионом: Центральный СПб / Центральный Екб; отдельно — Среда разработки.

В `dist` находится готовая статическая сборка. Для неё нужен HTTP-сервер; открытие index.html напрямую через file:// не предусмотрено.

В карточках активных инцидентов есть кнопка «Уведомить о восстановлении». Выбор и отмена реализованы в состоянии макета, серверная отправка уведомлений не подключена.

В демонстрации включён вид администратора: на вкладке событий кнопка «Добавить событие» открывает пустой Sidebar Consta. Для просмотра без админской кнопки используйте ?role=viewer. Это переключение макета, а не механизм авторизации.
